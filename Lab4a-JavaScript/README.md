
# BIC21203 Lab 4a - JavaScript

## Introduction
This lab demonstrates the use of JavaScript
functions, events, conditions, loops and DOM
manipulation.

## Question 1 - Interactive Text Changer
Changes the paragraph message when the user
clicks the Change Message button.

## Question 2 - Smart Number Validator
Accepts a number and checks whether it is
lower than, higher than or equal to 10.

## Question 3 - Dynamic Number Generator
Uses a for loop to generate an ordered list
from 1 to 5.

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open each question's index.html using Live Server.
4. Test the buttons and outputs.
